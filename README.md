# 🎵 JavaScript Music Player

A responsive browser-based music player built with HTML, CSS, and vanilla JavaScript as part of the FreeCodeCamp JavaScript Certification.

The project demonstrates core JavaScript concepts through an interactive music player, including DOM manipulation, event handling, arrays, objects, functions, and audio playback controls.

## ✨ Features

### Core Features

* Play and pause songs.
* Navigate to the next and previous songs.
* Display the current song title and artist.
* Highlight the currently playing song in the playlist.
* Automatically play the next song when the current song ends.
* Update accessible labels for player controls.
* Manage playback state using JavaScript.

### Planned Enhancements

* Responsive, modern user interface.
* Album artwork and improved playlist presentation.
* Interactive playback progress bar.
* Volume control and mute functionality.
* Shuffle and repeat modes.
* Search by song title or artist.
* Favorite songs with persistent storage.
* Improved keyboard navigation and accessibility.

*Planned enhancements will be marked as completed as they are implemented and tested.*

## 🛠️ Technologies

* **HTML5:** Page structure and audio element.
* **CSS3:** Styling, layout, and responsive design.
* **JavaScript (ES6+):** Playback logic, event handling, DOM manipulation, and application state.
* **Browser Audio API:** Audio playback and media events.
* **localStorage:** Planned persistence for favorites and preferences.

## 🚀 Getting Started

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/freecodecamp-music-player.git
   ```

2. Open the project folder:

   ```bash
   cd freecodecamp-music-player
   ```

3. Open `index.html` in your browser.

For a more consistent development experience, you can use the Live Server extension in Visual Studio Code.

Replace `YOUR-USERNAME` with your GitHub username.

## 🎧 How to Use

1. Open the application in your browser.
2. Select a song from the playlist.
3. Use the player controls to play, pause, or navigate between songs.
4. Follow the displayed song information to see which track is active.

Additional instructions will be added as new features are implemented.
